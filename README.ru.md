# Discord Game Idler

Русский · [English](README.md)

Discord Game Idler — экспериментальное приложение для Windows, созданное для накрутки часов и количества сыгранных игр ради значков профиля, а также для выполнения заданий Discord, в которых нужно поиграть в игру. Приложение имитирует игровую активность с помощью лёгких процессов Windows и публичного каталога игр Discord.

**При ручной проверке автором Discord распознал и засчитал имитацию игровой активности.** Зачёт может зависеть от игры, длительности сессии и условий задания. Таймер показывает локальное время сессии.

В одном клиенте доступны светлая и тёмная темы: поле **Тема** находится рядом с **Язык / Language**. По умолчанию включена тёмная тема; предупреждения выделены янтарным цветом в тёмной и коричневым в светлой.

## Скачать и запустить

В [последнем релизе](https://github.com/shemat0/discord-game-idler/releases/latest) репозитория [shemat0/discord-game-idler](https://github.com/shemat0/discord-game-idler) скачайте `DiscordGameIdler-<версия>-Windows-x64.zip`, распакуйте и откройте `DiscordGameIdler.exe`. Поддерживаются Windows 10/11 x64. В EXE включены Python и компактное нативное окно Windows. Перед запуском новой версии остановите сессию и закройте старую.

1. Откройте настольный Discord. Согласно [справке о значках](https://support.discord.com/hc/en-us/articles/44369363856663-Discord-Profile-Badges-What-Each-Badge-Means), для этих значков нужна настройка **Use data to personalize my Discord experience**. Также проверьте настройки игровой активности.
2. Найдите игры и нажмите **Добавить выбранные**. После массового добавления нажмите **Убрать конфликтующие**: для каждого имени EXE останется первая игра. Папки и регистр букв не учитываются; диалог показывает число удалений и до десяти названий. Кнопка **Очистить очередь** удаляет всю очередь до запуска, не меняя каталог и поиск. Во время операций, сессии или незавершённой остановки она недоступна.
3. Для начала выберите одну игру и проверьте **Discord → Зарегистрированные игры**. Появится окно имитации; его можно свернуть. Ручное добавление окна или работа локального таймера не доказывают зачёт официальной игры или значков.
4. Выберите от 1 до 10 в поле **Одновременно** (по умолчанию 10). Если игр меньше, запустятся только они, без дубликатов. Если вся очередь помещается, игры остаются запущенными. Большие очереди сменяются группами: например, 25 игр при лимите 10 дадут группы 10, 10 и 5, затем повтор.
5. **Остановить** или закрытие главного окна завершает все свои процессы. Закрытие любого окна имитации останавливает текущую группу. При ошибке запуска частичная группа останавливается. После ошибки остановки оставшиеся процессы сохраняются для повторной попытки. Автоматических перезапусков после ошибок нет.

## Независимые эксперименты (1.3.1)

При старте оба эксперимента **выключены** и работают независимо. Возле каждой галочки показано предупреждение **«Может снизить производительность системы»**. При включении любого из режимов также появляется предупреждение о повышенной нагрузке.

| Галочка возле поля | Выключена | Включена |
| --- | --- | --- |
| Количество одновременных игр | 1–10 игр | 1–100 игр; при включении выбранное число сохраняется |
| Интервал смены группы | 1–1440 минут | Настраиваемые 10–86400 секунд; по умолчанию 10 секунд |

После включения эксперимента количества под ним появится галочка **Суперэксперимент: до 1000**. По умолчанию она снята. Чтобы поднять лимит до 1000, отметьте **«Я осознаю риски»** в окне подтверждения и нажмите **«Включить»**. Интервал сохраняется. **Режим может некорректно работать с системой и потреблять больше 1 ГБ ОЗУ.** Снятие галочки ограничивает число значением 100. Выключение эксперимента количества сбрасывает суперэксперимент и ограничивает число значением 10.

Примеры: включите только эксперимент количества для **100 игр на 180 минут**; включите только эксперимент времени для **одной игры за раз со сменой каждые 10 секунд** по очереди из нескольких игр; включите оба для **групп по 100 игр со сменой каждые 10 секунд**. Если вся очередь помещается в выбранное число, она остаётся запущенной без перезапуска. Одна выбранная игра поэтому работает до остановки.

Переключение единиц времени сохраняет отдельные значения минут и секунд, в том числе введённые часы в минутах. Ни одна галочка не меняет другую галочку и её поле. При выключении эксперимента количества число выше 10 уменьшается до 10. Во время операций, сессии и незавершённой остановки обе галочки заблокированы.

Интервал работы группы отсчитывается **после полного запуска всех её процессов**. Большие очереди сменяются без перекрытия групп, остаток очереди не пропускается. Запуск, ротация и остановка идут в фоне. **«Остановить»** отменяет запуск между процессами и дожидается текущей системной операции перед завершением. Между операциями язык можно менять.

Автоматические проверки моделируют 100 процессов и сохраняют проверку десяти настоящих процессов; 100 окон они не открывают. Эти проверки охватывают работу локальных процессов. Они не измеряют, как Discord засчитывает короткие сессии или одновременные игры.

## Языки и локальные данные

Выберите **Язык / Language → Русский или English**. Надписи, текущие сообщения/ошибки и уже открытые окна имитации переключаются без перезапуска сессии. Названия игр остаются такими, как в каталоге. Первый язык определяется языком интерфейса Windows (русский → RU, остальные → EN); выбор сохраняется в `%LOCALAPPDATA%\DiscordGameIdler\settings.json`.

Переключайте **Тема → Тёмная / Светлая** без сброса очереди, сессии и таймеров. Уже запущенные окна имитации меняют оформление без перезапуска. Язык и тема сохраняются вместе в `settings.json`, не затирая друг друга. Во время фоновой операции переключатели оформления ненадолго блокируются.

Кэш, загруженный каталог, сгенерированные файлы helper и файл перевода окон находятся в `%LOCALAPPDATA%\DiscordGameIdler`. В пакетном окружении Windows эта папка может перенаправляться в его локальный кэш. Приложение не использует токен аккаунта, вход, self-bot или изменение клиента Discord. Сессия не запускается автоматически.

Встроен сокращённый публичный каталог от **4 ноября 2026 года**, содержащий 10 445 подходящих игр Windows. Кнопка **Обновить каталог** загружает свежие данные; при сетевой ошибке встроенный или сохранённый каталог остаётся доступным. Источник и атрибуция указаны в [информации о сторонних материалах](THIRD_PARTY_NOTICES.md).

## Запуск исходников

Нужны Windows x64 и Python 3.14 с Tkinter. При запуске из исходников используется собранное нативное окно, если оно доступно. Для резервного варианта нужен компилятор .NET Framework 4.x.

```powershell
python app.py
```

Также доступен `launch.cmd`. Проверки поведения и переводов:

```powershell
python -m unittest discover -v -p "test_*.py"
python -m py_compile app.py core.py i18n.py theme.py version.py build.py
```

Интеграционные проверки Windows ненадолго открывают собственные окна имитации и закрывают их. Они проверяют жизненный цикл окон и процессов, остановку десяти процессов, границы ротации, откат, фильтрацию конфликтов, переводы, сохранение выбора и смену языка без остановки. Зачёт значков Discord тесты не проверяют.

## Сборка релиза

Для сборки нужны Python 3.14 x64, пакеты из `requirements-build.txt`, Visual Studio Build Tools с набором C++ x64 и Windows SDK.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build.py
```

Скрипт выполняет проверки и создаёт `DiscordGameIdler.exe`, двуязычный ZIP и `SHA256SUMS.txt` в `dist/v1.3.1/`. Учётные данные GitHub для сборки не нужны. Проект не связан с Discord.
